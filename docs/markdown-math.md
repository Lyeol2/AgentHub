# Markdown 수식 예제

AgentHub의 Markdown 파일 미리보기와 AI 답변에서 LaTeX 수식을 볼 수 있습니다. 수식은 앱에 포함된 KaTeX로 표시하므로 인터넷 연결이 필요하지 않습니다. 파일 미리보기의 **원문** 버튼으로 작성한 문법을 확인할 수 있습니다.

## 문장 안의 수식

수식 앞뒤에 `$`를 하나씩 붙입니다.

```md
에너지와 질량의 관계는 $E = mc^2$입니다.
```

에너지와 질량의 관계는 $E = mc^2$입니다.

## 독립된 수식

수식 앞뒤에 `$$`를 붙이면 한 줄을 따로 사용합니다. 여러 줄로 작성할 수도 있습니다.

```md
$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

## 적분과 행렬

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

$$
A = \begin{bmatrix}
1 & 2 \\
3 & 4
\end{bmatrix}
$$

## 표 안의 수식

| 이름 | 수식 |
| --- | --- |
| 절댓값 | $|x|$ |
| 합 | $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$ |

`\(...\)`는 문장 안 수식, `\[...\]`는 독립된 수식으로도 사용할 수 있습니다. 언어를 `math`로 지정한 코드 블록도 수식으로 표시합니다. 그 외 코드 블록과 인라인 코드 안의 수식 문법은 그대로 보여 줍니다.

일반 달러 기호는 `\$`로 씁니다. 지원하지 않는 명령이나 잘못된 수식은 원문으로 표시됩니다. 지원하는 수식 문법은 [KaTeX 공식 문서](https://katex.org/docs/supported)를 참고하세요.
