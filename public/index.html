                              CLI 설치·업데이트·로그인 CLI 버전과 작업 상태를 확인합니다
                              
      
                              
      
                              Windows에서는 winget(Windows 패키지 관리자)이 없으면 자동으로 준비한 뒤 CLI를 설치합니다. 자동 설치가 실패하면 각 항목의 ‘수동 설치’에서 공식 설치 페이지와 명령을 확인하세요. 직접 설치하거나 오류를 해결한 뒤에는 ‘새로고침’을 누르세요. 로그인은 브라우저에서 계정을 확인하는 방식이라 비밀번호를 AgentHub에 넣지 않습니다. GitHub CLI는 Pull Request·릴리스 같은 GitHub 작업에 필요하고, 앱 업데이트에는 필요 없습니다.

                              CLI 버전
                              
      
                              
      
      
                              앱 시작 후와 12시간마다 설치된 CLI를 업데이트합니다. 실행 중인 작업이 끝날 때까지 기다리며, 설치 방식을 확인할 수 없는 CLI는 수동 업데이트 안내를 표시합니다.
                              
      
                              프로젝트
                              
      
                                
      
                                
        
        
      
                                
      
                                CLI 경로 
                                
      
                                PATH, npm 전역 설치 폴더, Claude 데스크톱 앱 폴더에서 자동으로 찾습니다. 다른 실행 파일을 쓰려면 직접 지정하세요.

                                연결 
                                
      
      
                                
        
        
                                
        
                                답변의 마지막 줄만 봅니다. "수정 필요 없음"처럼 키워드 뒤에 부정이 붙으면 맞지 않은 것으로 봅니다.
                                
      
                                
      
                                
        이 세션에서 나가는 다른 연결
        
                                  
      
                                  
      
      
      
      
                                  Git 결과나 새 작업의 작업 폴더에서 실행합니다. 새 작업에서는 받는 세션을 그 작업에 연결합니다. 기존 대화가 있는 세션은 같은 작업 폴더일 때만 실행할 수 있습니다.
                                  
      
      
                                  한 세션에서 나가는 연결은 키워드 → 성공·실패 → 그 외 순서로 먼저 맞은 쪽만 따라갑니다. "항상"은 언제나 함께 넘깁니다.
                                  
      
                                  보내는 세션의 마지막 답변, 바뀐 파일 목록, 작업 폴더 경로가 받는 세션의 요청으로 들어갑니다. 받는 세션이 실행 중이면 끝난 뒤 시작합니다. 자동 연결은 한 흐름에서 최대 8단계까지 이어집니다.
                                  
      
                                  
      
        
        
        
        
        
      
    
                                  
                                    

  
    
                                  
      
                                  새 명령
                                  
      
                                  
        
        
      
                                  
      
                                  
      
      
                                  
        
        
        
      
                                  
      
                                  
        
                                  
          
          
        
                                  
        
        
        
                                  
        
                                  
        
                                  소스 브랜치의 커밋된 변경만 --no-ff로 병합합니다. 대상 작업 폴더에 미커밋 변경이 있으면 실행하지 않습니다.
                                  
      
                                  
      
      
      
                                  
        
                                  입력 항목
                                  
        
                                  
        
        
                                  변수 이름은 영문·숫자·밑줄을 사용합니다. 이름은 영문 또는 밑줄로 시작합니다.
                                  
      
                                  
      
                                  
        
                                  
        
                                  반복 제어 → 성공 → 구현 → 테스트 → 실패 → 반복 제어로 연결하세요. 테스트 성공은 다음 작업으로 연결합니다.
                                  
      
                                  
      
                                  
        
        
        
      
                                  
      
                                  
        
        
                                  프로젝트 안의 상대 경로를 한 줄에 하나씩 입력하세요. 예: src, test/example.test.mjs
                                  
        
        
      
                                  
      
                                  
        
        
        
        
        
                                  
        
        
                                  {{scheduledAt}} 예약 시각 · {{triggeredAt}} 실제 시작 시각
                                  
      
                                  
      
                                  
        
        
        
                                  
      
                                  
      
                                  
        
                                  
        
        
        
                                  
          
          
        
                                  
        
                                  머리글은 "이름: 값"을 한 줄에 하나씩 적습니다. 머리글에 넣은 토큰은 이 PC의 AgentHub 데이터에 저장됩니다.
                                  
      
                                  
      
                                  
        
        
        
        
        
                                  {{body}} 받은 본문 · {{payload.필드}} JSON 본문의 값 · {{event}} GitHub 등의 이벤트 이름 · {{query.이름}} 주소의 쿼리 값 · {{method}} · {{receivedAt}}
                                  
      
                                  
      
                                  
        
        
                                  
          
                                  
            
            
          
                                  
          
          
                                  결과의 첫 줄을 제목으로 씁니다(최대 160자). 브랜치 이름은 GitFlow 설정을 따릅니다.
                                  
          
        
                                  
        
                                  
          
          
          
          
          
        
                                  
      
                                  
      
                                  
        모을 노드
        
                                    
      
                                    
      
                                    연결로 넘어오면 실행합니다. 종료 코드 0이면 "성공 시", 아니면 "실패 시" 연결로 넘어가고, 받는 세션에는 출력 마지막 부분이 함께 갑니다. 실행 전에 확인하려면 들어오는 연결에 "넘기기 전에 승인 받기"를 켜세요.

                                    세션 설정
                                    
      
      
      
                                    
        
        
                                    AI를 바꾸면 CLI 대화는 새로 시작합니다. 이어받기를 켜면 지금까지의 요청·답변·도구 사용·바뀐 파일을 정리해 다음 요청에 함께 넘깁니다. 작업 폴더·역할·연결·기록은 그대로입니다.
                                    
      
                                    
      
                                    
        
        
      
                                    
      
      
      
                                    모델·추론 강도·권한은 다음 요청부터 적용되고, 같은 AI면 대화는 그대로 이어집니다.
                                    
      
                                    
      
        
        
      
    
                                    
                                      

  
    
                                    
      
                                    프로젝트 제거 
                                    
      
                                    
      
                                      
        
                                    • 프로젝트 폴더와 파일, 스킬 파일은 그대로 둡니다.
                                      • 
        
                                    • Claude Code·Codex의 대화 기록 파일도 그대로 두고, 목록에서만 숨깁니다.
                                      • 
        
                                    • 나중에 같은 폴더를 다시 추가하거나 거기서 세션을 만들면 다시 보입니다.
                                      • 
      
                                    
      
      
      
                                    
      
        
        
      
    
                                    
                                      

  
    
                                    
      
                                    작업 보내기 
                                    
      
      
                                    
        받을 팀원 여러 명 고를 수 있습니다 · 고르지 않으면 팀 공용 작업
        
                                    
        
                                    
      
                                    
      
      
                                    GitHub 프로필 이름을 자동으로 불러옵니다. 내 이름을 팀원에게 보이려면 GitHub 프로필의 Name을 설정하세요. 여기서 붙인 이름은 이 컴퓨터에만 저장되고 GitHub 이름보다 먼저 보입니다.
                                    
      
      
                                    
        
        
        
        
      
                                    
      
      
                                    
      
                                    GitHub 이슈로 만들고 agenthub 라벨과 고른 담당자를 지정합니다. 고른 팀원 모두의 받은 작업함에 나타나고, 아무도 고르지 않으면 팀원 모두의 공용 작업함에 나타나 먼저 맡은 사람이 담당합니다. 토큰처럼 보이는 값은 가려서 올립니다.
                                    
      
                                    
      
        
        
      
    
                                    
                                      

  
    
                                    
      
                                    기록 가져오기 
                                    
      
                                    기록 내보내기로 저장한 세션 파일(.agenthub)이나 Markdown 문서를 가져옵니다. 대화 기록과 함께 내보낸 이미지·첨부도 다시 붙입니다.
                                    
      
      
                                    
      
                                    
        
        
      
                                    
      
                                    
        
        
        
        
                                    켜 두면 새 세션의 첫 요청에 가져온 기록을 붙여 이어서 작업합니다. 끄면 화면에서 기록만 봅니다. .agenthub 파일은 같은 AI면 모델·권한·역할·스킬도 되살립니다.
                                    
      
                                    
      
                                    지금 세션의 다음 요청 앞에 이 기록을 정리해 붙입니다. 대화는 그대로 이어지고, AI가 기록을 읽은 뒤 요청을 처리합니다.
                                    
      
                                    
      
        
        
      
    
                                    
                                      

  
    
                                    
      
                                    공유 노트 
                                    
      
      
                                    이 프로젝트의 모든 세션이 board_read·board_post 도구로 읽고 덧붙입니다. 세션끼리 정한 API 모양, 결정 사항, 진행 상황을 남기는 곳입니다.
                                    
      
                                    
      
        
        
        
        
      
    
                                    
                                      

  
    
                                    
      
                                    세션 역할
                                    
      
      
                                    역할은 새 대화의 첫 요청에 붙습니다. 대화 중에 바꾸면 다음 요청에 바뀐 역할을 함께 보냅니다.
                                    
      
                                    
      
        
        
      
    
                                    
                                      

  
    
                                    
      
                                    변경 사항 
                                    
      
                                    
      
                                    
      
    
                                    
                                      

  
    
                                    
      
                                    새 작업
                                    
      
                                    
      
                                    
        
                                    하고 싶은 일을 적으면 초안을 만듭니다. 내용을 확인하고 ‘만들기’를 누르면 작업과 세션을 만들고, 요청을 세션 입력창에 채워 둡니다.
                                    
        
                                    
        
        
        
                                    초안을 작성할 AI
                                    기존 CLI 로그인을 사용합니다. 아래 작업 담당 AI와 별도로 선택할 수 있습니다.
                                    
        
                                    
        
                                    
      
                                    
      
                                    작업 내용 확인
      
      
                                    
      
      
      
      
      
                                    
      
                                    세부 설정 · 브랜치, 작업 폴더 이름, 모델, 권한
      
      
                                    
        
        
                                    
        
      
                                    
      
      
      
      
      
                                    
      
                                    
      
                                    
        
        
      
                                    
      
      
      
                                    원격 main과 기준 브랜치를 확인한 뒤 작업 브랜치·폴더·세션을 연결합니다.
                                    
      
                                    
      
                                    
      
                                    
      
    
                                    
                                      

  
    
                                    
      
                                    GitFlow 브랜치 설정
                                    
      
                                    이 프로젝트에서 새 작업을 만들 때 사용할 이름입니다. 대소문자를 구분하므로 실제 브랜치 이름과 같게 입력해 주세요.
                                    
      
                                    
        
        
      
                                    
      
      
      
      
      
                                    저장해도 Git 브랜치 이름을 바꾸지는 않습니다. 기존 작업은 생성할 때의 설정을 유지합니다.
                                    
      
                                    
      
                                    
      
    
                                    
                                      

  
    
                                    
      
                                    GitHub 이슈 연결
                                    
      
                                    
      
      
      
      
                                    새 이슈는 내 GitHub 계정에 지정하고 agenthub 라벨을 붙입니다. 이 작업으로 만든 PR 설명에 Closes #번호를 넣어, PR이 기본 브랜치에 병합되면 GitHub가 이슈를 닫습니다.
                                    
      
                                    
      
    
                                    
                                      

  
    
                                    
      
                                    변경 검토 및 반영
                                    
      
                                    
      
                                    
      
      
                                    
      
                                    
      
                                    
      
                                    커밋 확인
