프로젝트

Claude Code·Codex 기록에서 자동으로 찾은 프로젝트입니다. 세션을 가져오거나 새로 만들면 AgentHub 프로젝트로 등록됩니다.

세션 흐름 카드를 눌러 고르고 두 번 눌러 엽니다(가운데 버튼·Ctrl+두 번 누르기는 새 창). 빈 곳을 끌면 여러 개를 고르고, 고른 카드는 함께 옮겨집니다. ● 손잡이를 끌어 다른 카드에 연결합니다

Claude Code · Codex 세션 이 프로젝트에서 연 세션

가져오면 기존 대화 기록을 보여 주고, 다음 요청부터 같은 CLI 세션을 이어서 실행합니다. 다른 앱에서 같은 세션을 동시에 쓰지 마세요.

오케스트레이터

      무엇을 도와드릴까요?

      위에서 AI·모델·추론 강도를 고르고 바로 물어보세요. 파일 수정이나 명령 실행 없이 대화만 하며, 설치된 CLI의 로그인(구독)을 씁니다.

          새 세션

          작업 폴더는 현재 커밋(HEAD) 기준으로 만들어집니다. 커밋하지 않은 수정은 포함되지 않습니다. Unity 프로젝트는 작업 폴더에서 열면 Library를 다시 만듭니다.

          프로젝트 없이 대화만 합니다. 파일 수정이나 명령 실행은 하지 않으며, 설치된 CLI의 로그인(구독)을 그대로 씁니다.

          CLI 설치·로그인 AgentHub가 쓰는 CLI를 이 PC에 설치하고 로그인합니다

          설치는 winget(Windows 패키지 관리자)으로 합니다. 로그인은 브라우저에서 계정을 확인하는 방식이라 비밀번호를 AgentHub에 넣지 않습니다. GitHub CLI는 릴리스 같은 GitHub 작업에만 필요하고, 앱 업데이트에는 필요 없습니다.

            흐름 시작 AGENTHUB.md의 흐름 템플릿으로 세션을 만들고 연결합니다

            연결

            답변의 마지막 줄만 봅니다. "수정 필요 없음"처럼 키워드 뒤에 부정이 붙으면 맞지 않은 것으로 봅니다.

            이 세션에서 나가는 다른 연결

              한 세션에서 나가는 연결은 키워드 → 성공·실패 → 그 외 순서로 먼저 맞은 쪽만 따라갑니다. "항상"은 언제나 함께 넘깁니다.

              보내는 세션의 마지막 답변, 바뀐 파일 목록, 작업 폴더 경로가 받는 세션의 요청으로 들어갑니다. 받는 세션이 실행 중이면 끝난 뒤 시작합니다. 자동 연결은 한 흐름에서 최대 8단계까지 이어집니다.

              새 명령

              연결로 넘어오면 실행합니다. 종료 코드 0이면 "성공 시", 아니면 "실패 시" 연결로 넘어가고, 받는 세션에는 출력 마지막 부분이 함께 갑니다. 실행 전에 확인하려면 들어오는 연결에 "넘기기 전에 승인 받기"를 켜세요.

              세션 설정
              
      
      
      
              
        
        
              AI를 바꾸면 CLI 대화는 새로 시작합니다. 이어받기를 켜면 지금까지의 요청·답변·도구 사용·바뀐 파일을 정리해 다음 요청에 함께 넘깁니다. 작업 폴더·역할·연결·기록은 그대로입니다.
              
      
              
      
              
        
        
      
              
      
      
      
              모델·추론 강도·권한은 다음 요청부터 적용되고, 같은 AI면 대화는 그대로 이어집니다.
